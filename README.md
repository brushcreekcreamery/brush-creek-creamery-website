# Brush Creek Creamery Website

Simple multi-page static website for Brush Creek Creamery — artisan cheese handcrafted in Deary, Idaho.

## Pages

- `index.html` — Home
- `cheeses.html` — Our Cheeses
- `story.html` — Our Story
- `awards.html` — Awards
- `order.html` — Order form (mailto)

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Images

Product and farm photos belong in the `images/` folder (paths are referenced in the HTML).
